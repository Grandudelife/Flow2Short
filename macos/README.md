# Flow2Short Studio for macOS

نسخهٔ مستقل برای مک‌های Apple Silicon (M1 و جدیدتر)، با macOS 13 و جدیدتر.
مبنای کد: `Grandudelife/Flow2Short`، commit `044b1bf476e17df0fc9a1c9519b733ccac44f85f`، نسخهٔ ۲.۳.

این نسخه در شاخهٔ [`macos-native`](https://github.com/Grandudelife/Flow2Short/tree/macos-native) منتشر شده است.
[بستهٔ آمادهٔ مک را از Release دانلود کنید](https://github.com/Grandudelife/Flow2Short/releases/tag/macos-v1.0.0).
فایل `Flow2Short-Mac.zip` شامل اپ است؛ `SHA256SUMS.txt` برای بررسی صحت دانلود ارائه می‌شود.
دسترسی به نسخه تابع دسترسی شما به همین مخزن خصوصی است.

## اجرا

`Flow2Short Studio.app` را باز کنید. می‌توانید آن را به پوشهٔ Applications منتقل کنید.
اگر macOS به‌علت نداشتن notarization اجازهٔ اجرا نداد، پس از بررسی منبع دانلود،
در System Settings → Privacy & Security گزینهٔ Open Anyway مربوط به همین اپ را انتخاب کنید.
نسخهٔ آماده به Python، Go، Node، مرورگر یا ترمینال نیاز ندارد. موتور FFmpeg و
سرور محلی داخل اپ بسته‌بندی شده‌اند. تمام پردازش ویدئو محلی است؛ قابلیت‌های
Google همان رفتار و نیاز به اینترنت/کلید API نسخهٔ فعلی را حفظ می‌کنند.

این پیاده‌سازی یک اپ هیبریدی است: پنجره، منو، پنجرهٔ انتخاب/ذخیرهٔ فایل و
مدیریت اجرا با Swift/AppKit ساخته شده‌اند، رندر با FFmpeg بومی انجام می‌شود،
و رابط فارسی فعلی در WebKit داخلی اپ نمایش داده می‌شود. بازنویسی رابط با
SwiftUI انجام نشده است.

میان‌برها: ⌘I افزودن کلیپ، ⌘O بازکردن Recipe، ⌘S ذخیرهٔ Recipe، ⇧⌘E ساخت خروجی،
⌘, تنظیمات، ⌘Q خروج. فایل Recipe مانند نسخهٔ اصلی رسانه‌ها را در خود ذخیره نمی‌کند.
ذخیرهٔ خودکار تنظیمات و Recipe میان اجراها مستقل از درگاه موقت سرور حفظ می‌شود.
خروج هنگام پردازش نیاز به تأیید دارد و پس از خروج فایل‌های موقت پاک می‌شوند.

سرور فقط روی 127.0.0.1 و درگاه آزاد سیستم گوش می‌دهد. عملیات داخلی به قابلیت
تصادفی مخصوص همان اجرای اپ نیاز دارند؛ این مقدار در صفحات سرو‌شده وجود ندارد.

## ساخت از سورس

به Apple Command Line Tools (Swift)، Go و Python 3 نیاز دارید:

```sh
bash macos/build.sh /path/to/output
```

اسکریپت ابزارهای FFmpeg را با نسخهٔ مشخص و کنترل SHA-256 دریافت می‌کند.
برای ابزارهای از قبل دریافت‌شده، `NATIVE_TOOLS_DIR` را تنظیم کنید؛ برای Go
در مسیر دیگر، `GO_BIN` را تنظیم کنید. بستهٔ فعلی arm64 است.

```sh
cd server && go test ./...
```

امضای بسته ad-hoc برای استفادهٔ محلی است. امضای Developer ID و notarization
برای انتشار عمومی با حساب Apple Developer انجام می‌شود.
