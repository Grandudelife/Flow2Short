# Flow2Short Studio for Windows 1.0.0

نسخهٔ مستقل ویندوز اکنون در دسترس است؛ فایل **Flow2Short-Windows.exe** را دانلود و اجرا کنید.

- ویندوز ۱۰ نسخهٔ ۱۸۰۹ یا جدیدتر / ویندوز ۱۱، پردازندهٔ Intel/AMD ۶۴بیتی (x64).
- EXE قابل حمل با .NET و موتور بومی FFmpeg داخلی؛ بدون نیاز به Python، Go یا ترمینال.
- نیازمند Microsoft Edge WebView2 Runtime؛ [دانلود رسمی Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/).
- پنجره، منوها و پنجرهٔ انتخاب/ذخیرهٔ فایل بومی، همراه رابط فارسی داخل WebView2.
- رندر محلی MP4، ترنزیشن، صدا و زیرنویس؛ حفظ تنظیمات و Recipe میان اجراها.
- تصویر و آیکون فعلی اپلیکیشن حفظ شده‌اند.
- امکانات Google Gemini نیاز به اینترنت و کلید API خود کاربر دارند.

این پیش‌انتشار امضای تجاری Authenticode ندارد. فایل `SHA256SUMS-Windows.txt`
برای بررسی صحت دانلود ارائه شده است. تست‌های خودکار روی ویندوز، رندر واقعی و
لغو آن، اجرای EXE، ذخیرهٔ فایل Blob، بازیابی تنظیمات و خاموش‌شدن سرویس را بررسی می‌کنند.
