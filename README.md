# Flow2Short Studio

یک استودیوی فارسی، آفلاین و متن‌باز برای تبدیل کلیپ‌های Google Flow به ویدئوی عمودی آمادهٔ انتشار؛ بدون نیاز به نرم‌افزار تدوین حرفه‌ای و بدون آپلود فایل‌های شما روی سرور.

![نمای Flow2Short Studio](design/flow2short-approved-comp.png)

## امکانات

- ورود چند کلیپ MP4، MOV یا WebM و تغییر ترتیب آن‌ها
- برش ابتدا و انتهای هر کلیپ و تنظیم مستقل صدای اصلی
- افزودن نریشن و موسیقی پس‌زمینه
- پیش‌نمایش یکپارچهٔ تصویر، برش‌ها، صداها و زیرنویس پیش از خروجی
- ورود فایل SRT و انتخاب از میان ۶ استایل حرفه‌ای زیرنویس
- زیرنویس پانچ کلمه‌به‌کلمه با گروه‌های ۳ یا ۴ کلمه‌ای و حالت تک‌کلمه‌ای
- تنظیم جلو یا عقب افتادن همهٔ زیرنویس‌ها بر حسب میلی‌ثانیه
- تنظیم رنگ، اندازه و جایگاه زیرنویس و تثبیت آن روی ویدئوی خروجی
- افزودن لوگوی PNG، JPG یا WebP به‌صورت واترمارک در ۹ جایگاه
- ذخیره و بازکردن Recipe پروژه
- خروجی MP4 عمودی در ابعاد 1080×1920 یا 720×1280
- رابط فارسی RTL با فونت Vazirmatn
- نصب به‌شکل PWA و استفادهٔ آفلاین پس از نخستین بارگذاری

## شروع سریع

> فایل `app/index.html` را مستقیم باز نکنید. مرورگر اجرای موتور ویدئو را روی آدرس‌های `file://` محدود می‌کند و در این حالت ساخت خروجی انجام نمی‌شود.

### macOS

1. پروژه را دانلود و از حالت فشرده خارج کنید.
2. در پوشهٔ اصلی پروژه روی `Start Flow2Short.command` دوبار کلیک کنید.
3. اگر macOS اجرای آن را مسدود کرد، روی فایل راست‌کلیک و **Open** را انتخاب کنید.
4. پنجرهٔ Terminal را تا پایان کار باز نگه دارید.
5. برنامه باید با آدرسی شبیه `http://127.0.0.1:43121` در مرورگر باز شود.

لانچر مک ابتدا Python 3 و سپس Ruby داخلی سیستم را امتحان می‌کند.

### Windows

1. پروژه را دانلود و از حالت فشرده خارج کنید.
2. در پوشهٔ اصلی روی `Start Flow2Short Windows.bat` دوبار کلیک کنید.
3. پنجرهٔ بازشده را تا پایان کار نبندید.
4. برنامه باید با آدرسی شبیه `http://127.0.0.1:43121` باز شود.

لانچر فعلی ویندوز به Python 3 نیاز دارد. بسته‌های مستقل ساخته‌شده در بخش GitHub Releases این وابستگی را ندارند.

## راهنمای کامل استفاده

### ۱. افزودن کلیپ‌ها

فایل‌ها را روی کادر ورود بکشید یا روی آن کلیک و کلیپ‌ها را انتخاب کنید. برای نتیجهٔ بهتر:

- از کلیپ‌های عمودی 9:16 استفاده کنید.
- بهتر است رزولوشن و نرخ فریم فایل‌ها یکسان باشد.
- اگر ترتیب مهم است، فایل‌ها را پیش از ورود شماره‌گذاری کنید؛ مانند `01.mp4` و `02.mp4`.

### ۲. مرتب‌سازی، برش و صدای کلیپ

- با دستگیرهٔ هر ردیف، کلیپ را جابه‌جا کنید.
- زمان شروع و پایان را برای حذف بخش‌های اضافی تغییر دهید.
- با دکمهٔ پخش، همان کلیپ را بررسی کنید.
- اسلایدر «صدای اصلی کلیپ» میزان صدای خود ویدئو را تعیین می‌کند.

اگر نریشن دارید، معمولاً تنظیم صدای کلیپ‌ها روی حدود ۰ تا ۳۵ درصد نتیجهٔ واضح‌تری می‌دهد.

### ۳. افزودن نریشن و موسیقی

در بخش «لایه‌های صدا»:

1. برای نریشن، فایل خروجی Google AI Studio یا هر فایل صوتی سازگار را انتخاب کنید.
2. برای موسیقی پس‌زمینه، فایل موسیقی را اضافه کنید.
3. بلندی هر لایه را جداگانه تنظیم کنید.

اگر موسیقی کوتاه‌تر از ویدئو باشد، هنگام خروجی تکرار می‌شود. برای حفظ وضوح گفتار، حجم موسیقی را معمولاً بین ۱۰ تا ۲۵ درصد نگه دارید.

### ۴. ساخت زیرنویس حرفه‌ای

فایل زیرنویس باید با فرمت SRT باشد. نمونه:

</div>

```srt
1
00:00:00,000 --> 00:00:02,400
ایدهٔ بزرگ بعدی تو از همین‌جا شروع می‌شود.

2
00:00:02,400 --> 00:00:05,000
قبل از بقیه آن را بساز.
```

<div dir="rtl">

پس از ورود SRT:

1. یکی از استایل‌های **پاپ بولد، تمیز، باکس، مینت، نئون یا مینیمال** را انتخاب کنید.
2. برای SRT کلمه‌به‌کلمه، نمایش پانچ ۳ یا ۴ کلمه‌ای یا حالت تک‌کلمه‌ای را انتخاب کنید.
3. اندازهٔ متن، رنگ و محل نمایش را تنظیم کنید.
4. اگر متن با صدا هماهنگ نیست، مقدار «هماهنگی زیرنویس با صدا» را تغییر دهید؛ عدد منفی متن را زودتر و عدد مثبت آن را دیرتر نشان می‌دهد.
5. گزینهٔ تثبیت زیرنویس را روشن نگه دارید تا استایل روی فایل نهایی حک شود.
6. نتیجه را در پیش‌نمایش ترکیبی بررسی کنید.

تنظیمات استایل، پانچ و سینک هم در پیش‌نمایش و هم در خروجی نهایی اعمال می‌شوند. برای نمایش دقیق کلمه‌به‌کلمه، هر کلمه باید در SRT بازهٔ زمانی جداگانه داشته باشد. برنامه این ساختار را خودکار تشخیص می‌دهد و پس از رسیدن به تعداد انتخاب‌شده، نشانهٔ پایان جمله یا مکث بیش از ۵۵۰ میلی‌ثانیه گروه تازه‌ای می‌سازد.

### ۵. پیش‌نمایش میکس

روی «پیش‌نمایش میکس» بزنید تا برش کلیپ‌ها، صدای اصلی، نریشن، موسیقی و زیرنویس به‌صورت هم‌زمان پخش شوند. با نوار زمان می‌توانید به هر نقطه بروید و هماهنگی صدا و تصویر را بسنجید.

پیش‌نمایش برای بررسی سریع ساخته شده است؛ کیفیت نهایی پس از رندر کامل می‌شود.

### ۶. افزودن واترمارک

در مرحلهٔ «واترمارک»:

1. یک فایل PNG، JPG یا WebP انتخاب کنید؛ برای لوگوی بدون پس‌زمینه PNG یا WebP مناسب‌تر است.
2. جایگاه لوگو را از میان ۹ نقطهٔ قاب انتخاب کنید.
3. اندازهٔ لوگو را نسبت به عرض ویدئو تنظیم کنید.
4. نتیجه را روی قاب زنده یا در پنجرهٔ پیش‌نمایش ترکیب ببینید.

واترمارک انتخاب‌شده روی تمام کلیپ‌ها قرار می‌گیرد و هنگام خروجی روی تصویر تثبیت می‌شود.

### ۷. ساخت ویدئوی نهایی

1. در بخش خروجی، ابعاد `1080×1920` یا `720×1280` را انتخاب کنید.
2. تنظیمات صدا و زیرنویس را یک بار در پیش‌نمایش کنترل کنید.
3. روی «ساخت ویدئوی نهایی» بزنید.
4. تا پایان پردازش، تب مرورگر و پنجرهٔ لانچر را باز نگه دارید.
5. پس از تکمیل، فایل MP4 را دانلود کنید.

همهٔ پردازش‌ها محلی هستند. سرعت خروجی به طول ویدئو، رزولوشن و توان دستگاه بستگی دارد.

### ۸. ذخیرهٔ پروژه

گزینهٔ ذخیرهٔ Recipe یک فایل JSON از ترتیب، برش‌ها، حجم صداها، استایل زیرنویس و تنظیمات خروجی می‌سازد. فایل‌های رسانه‌ای به‌دلیل حفظ حریم خصوصی داخل Recipe کپی نمی‌شوند؛ هنگام بازکردن پروژه، همان فایل‌های اصلی را دوباره معرفی کنید.

## رفع خطاهای رایج

| پیام «موتور ویدئو از فایل مستقیم اجرا نمی‌شود» | برنامه را با لانچر اجرا کنید؛ در نوار آدرس باید `http://127.0.0.1:43121` دیده شود، نه `File`. |
| دکمهٔ ساخت ویدئو غیرفعال است | دست‌کم یک کلیپ اضافه کنید و مطمئن شوید برنامه با `http://` باز شده است. |
| macOS فایل لانچر را باز نمی‌کند | روی `Start Flow2Short.command` راست‌کلیک و **Open** را انتخاب کنید. |
| زیرنویس دیده نمی‌شود | ساختار و زمان‌بندی SRT را بررسی و گزینهٔ تثبیت زیرنویس را روشن کنید. |
| پانچ کلمه‌به‌کلمه فعال نمی‌شود | مطمئن شوید هر کلمه در SRT یک بازهٔ زمانی جداگانه دارد. |
| لوگو پس‌زمینهٔ سفید دارد | از فایل PNG یا WebP با پس‌زمینهٔ شفاف استفاده کنید. |
| مرورگر یا آیفون هنگام رندر بسته می‌شود | خروجی 720p را امتحان کنید یا Recipe را ذخیره و پروژه را روی دسکتاپ رندر کنید. |
| خروجی زیرنویس تصویری ندارد | Chrome به‌روز را امتحان کنید؛ بعضی مرورگرها از فیلتر زیرنویس موتور داخلی پشتیبانی نمی‌کنند. |

## حریم خصوصی

تمام ویدئوها و صداها داخل مرورگر و روی دستگاه شما پردازش می‌شوند. برنامه رسانه‌ها را به سرور ارسال نمی‌کند و Recipe نیز فقط تنظیمات و نام فایل‌ها را نگه می‌دارد.

## نصب روی iPhone و iPad

نسخهٔ GitHub Pages را در Safari باز کنید و از **Share → Add to Home Screen** برنامه را نصب کنید. پس از نخستین بارگذاری کامل موتور، برنامه می‌تواند آفلاین باز شود. برای پروژه‌های سنگین 1080p استفاده از دسکتاپ پیشنهاد می‌شود.

## اجرای توسعه

هر وب‌سرور استاتیک می‌تواند پوشهٔ `app/` را سرو کند. لانچر محلی با Go نوشته شده است:

</div>

```bash
go run ./server
```

<div dir="rtl">

سپس آدرس `http://127.0.0.1:43121` را باز کنید.

## انتشار روی GitHub Pages

Workflow آماده در `.github/workflows/pages.yml` پوشهٔ `app/` را منتشر می‌کند:

1. در Repository به **Settings → Pages** بروید.
2. مقدار Source را روی **GitHub Actions** قرار دهید.
3. در تب Actions، workflow با نام **Deploy Flow2Short to GitHub Pages** را اجرا کنید.

## ساخت لانچرهای مستقل

Workflow بخش Release برای ساخت بسته‌های اجرایی آماده است. یک tag نسخه بسازید و Push کنید:

</div>

```bash
git tag v1.0.0
git push origin v1.0.0
```

<div dir="rtl">

سپس فایل‌های ساخته‌شده در بخش Releases قرار می‌گیرند.

## نکات فنی

- پردازش ویدئو با FFmpeg WebAssembly انجام می‌شود و از FFmpeg بومی کندتر است.
- زیرنویس SRT هنگام رندر به ASS تبدیل می‌شود تا استایل انتخاب‌شده روی تصویر اعمال شود.
- اگر مرورگر از فیلتر زیرنویس پشتیبانی نکند، برنامه با مسیر جایگزین ویدئو را بدون زیرنویس تصویری می‌سازد و SRT اصلی دست‌نخورده باقی می‌ماند.
- Recipe پروژه رسانه‌ها را در JSON قرار نمی‌دهد.

## مجوز و وابستگی‌ها

برای کد اختصاصی پروژه هنوز مجوزی انتخاب نشده است. وابستگی‌های بسته‌شده مجوزهای مستقل دارند؛ جزئیات در `THIRD_PARTY_NOTICES.md` آمده است. پیش از عمومی‌کردن مخزن، مجوز نهایی پروژه را آگاهانه انتخاب کنید.
